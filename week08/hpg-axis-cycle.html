One axis, two patterns

Hypothalamus → GnRH (pulsatile) → anterior pituitary → FSH & LH → gonads → sex steroids + gametes, with feedback.

Male — steady

  • LH → Leydig cells → testosterone
  • FSH → Sertoli cells → androgen-binding protein (keeps intratesticular testosterone high) + inhibin
  • Both are required for spermatogenesis
  • Testosterone & inhibin give negative feedback; output is relatively constant

Female — cyclic

  • Follicular: FSH/LH → estrogen; negative feedback keeps FSH in check
  • Ovulation: high estrogen flips to positive feedback → LH surge → ovulation
  • Luteal: corpus luteum → progesterone + estrogen → negative feedback
  • No pregnancy → luteal regression → hormones fall → menstruation
The big idea: the same hierarchy produces a steady male pattern and a timed, cyclic female pattern — the difference is the brief positive-feedback LH surge.
